はじめまして、tokiolab (トキオラボ) と申します。

2026年9月27日 に本ブログを開設しました。

このブログでは、IT・技術系のネタを中心に書いていく予定です。その他に、最近見た映画の話や好きな音楽のことなど、日々の雑多なことも書くかもしれません。

# このブログの技術スタック (Jamstack構成)

このブログは、いわゆる**Jamstack構成**で構築しています。

- フレームワーク : Astro
- ヘッドレスCMS : MicroCMS
- インフラ : Cloudflare Pages

GitHub Pages + Markdownでコンテンツをホストする方法も考えましたが、mdファイルでの画像の取り扱いに苦手意識があったりなどで、リッチテキストを扱えるMicroCMSを選びました。静的なサイトでは、今のところこの構成が気に入っています。

# AI時代になぜ個人ブログ？

AI時代になぜ個人ブログ？というところを、少し理由を整理しようと思います。

昨今、調べたいことはググらずにAIに聞くことが増えました(ググるではなく何ていうのかな？チャピる？)。

ブログを書いたところで、みんなググらないのだから見られることがないのでは？と僕も思います。

単なるノウハウのアウトプットでは以前ほどの価値はないのかも..。

しかし、ブログを書く過程は、依然価値があると思っています。自分の理解したことや考えた事を言葉にするのって難しいですよね。

それなりの分量の文章を、自分の頭だけで書けるようになりたいし、文章を書く上での自分なりの型も作りたいと思っています。

そのため、このブログは全て自分で書くという制約を設けようと思います。

これから細く長く続けていこうと思うので、どうぞよろしくお願いします。
