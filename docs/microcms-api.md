# microCMS API 定義

次の3つの **リスト形式** API を作成します。コンテンツIDはURLと絞り込み条件に使うため、英小文字・数字・ハイフンによるslug形式にしてください。

| API名 | エンドポイント | 用途 |
| --- | --- | --- |
| 記事 | `blogs` | 記事本文と分類の参照元 |
| カテゴリ | `categories` | 記事の主分類マスター |
| タグ | `tags` | 記事の横断的な話題マスター |

`categories` には `name`（テキストフィールド、必須）と任意の `description`（テキストエリア）を、`tags` には `name`（テキストフィールド、必須）を追加します。

| 表示名 | フィールド ID | 種類 | 必須 | 用途 |
| --- | --- | --- | --- | --- |
| タイトル | `title` | テキストフィールド | はい | 一覧・詳細の見出し |
| 本文 | `content` | リッチエディタ | はい | 詳細ページ本文 |
| 抜粋 | `excerpt` | テキストエリア | いいえ | 一覧とmeta descriptionの要約 |
| カテゴリー | `category` | コンテンツ参照（`categories`） | はい | 記事の主分類 |
| タグ | `tags` | 複数コンテンツ参照（`tags`） | いいえ | 記事を横断する複数の話題ラベル |
| アイキャッチ | `eyecatch` | 画像 | いいえ | 一覧・詳細の画像 |

microCMS の標準フィールド `id`、`publishedAt`、`updatedAt` は追加不要です。公開状態の記事だけが、Cloudflare のビルド時に静的 HTML として生成されます。
